# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Static single HTML file with embedded CSS/JS. Booking calendar via Cal.com embed (free, no backend needed). Deposit payments via Stripe payment links. Contact form via Web3Forms. Chosen for zero maintenance, instant deploy, and consistency with user's other projects.

## Users

People in the San Fernando Valley / Los Angeles area looking for a tattoo artist. They browse work on Instagram, find the site through the bio link or search, want to see the portfolio, check availability, and book + pay a deposit — all without DMs or phone calls.

## Product Purpose

Portfolio and booking site for JB Tattoos (Jordan / Jay B), a tattoo artist. The site replaces the current Instagram-only workflow by giving clients a place to view work, check availability on a calendar, book an appointment, and pay a deposit online.

## Positioning

Personal artist portfolio with integrated booking and deposit payment — most tattoo artists rely solely on Instagram DMs. A dedicated site with real booking flow signals professionalism and reduces back-and-forth.

## Operating Context

Clients currently reach out via Instagram DM or phone (818-688-1684). The booking calendar replaces that with self-service scheduling. Deposits secure appointments and reduce no-shows.

## Capabilities and Constraints

- Portfolio gallery of tattoo work
- Calendar booking system (Cal.com embed)
- Deposit payment (Stripe payment link)
- Contact form (Web3Forms)
- No backend, no database, no auth
- Single static HTML file
- Mobile-first (most traffic from Instagram bio link)
